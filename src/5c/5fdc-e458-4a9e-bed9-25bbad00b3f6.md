## 从注意力到记忆：人类认知与 Transformer 架构的对照

> Attention is all you need.

从大量信息中选择性地处理一部分。但若将人类注意力与 Transformer 的自注意力机制
并置对照，会发现两者共享的只是“选择性分配资源”这一抽象原则；在容量约束、信息
通路、意图来源与功能分工上，它们并不相同。进一步追问还会暴露当前大语言模型的
一个结构性短板：它擅长将当前上下文混合起来做整合，却不擅长将长期知识分区存放、
版本化管理、按需回视。本文沿此线索，先梳理人类注意力与记忆的研究图景，再对照
Transformer 的注意力、FFN 与 MoE，最后讨论一种方向性的判断：应拆分的是记忆，
不是网络；应外部化的是上下文管理，不是继续扩张上下文窗口。

---

### 一、人类注意力：有限资源的分配系统

认知心理学讨论注意力，起点往往是有限性。人的信息加工容量并非无限，因此必须有
一套机制决定什么进入焦点。Broadbent 于 1958 年提出的过滤器模型认为，神经系统
高级中枢的加工能力有限，如同一个瓶颈，需要过滤器对海量感官信息筛选，只让少量
信息通过进入高级分析。但后续研究发现，未被注意的信息并非完全被屏蔽。鸡尾酒会
效应表明，人在嘈杂中专注于自己的谈话，却能突然捕捉到远处有人提到自己的名字。
这说明未注意通道也获得了某种程度的加工，只是强度被衰减，不是彻底阻断，这正是
Treisman 衰减模型的核心。

容量瓶颈相当具体。研究共识是，人同时只能关注大约三到四个独立物体；关注对象
越多，对每个对象的细节加工越粗糙，两者之间存在明显权衡。注意力也不是单一功能，
至少可区分选择性注意、分散性注意、持续性注意与空间注意。空间注意可以是外显的，
伴随眼动；也可以是内隐的，眼球不动、心理上聚焦某处。驱动方式则分为内源性注意，
由目标主动引导；与外源性注意，由突然的响声、闪光等刺激捕获。

在神经层面，一个颇具影响力的解释是偏向竞争模型。大量感官信息在脑中竞争有限的
神经表征资源，注意力并不凭空创造新信号，其作用是增强被注意刺激的神经活动、抑制
竞争刺激的活动，进而偏置竞争的胜者。在更微观的尺度上，注意力会选择性同步那些
编码目标特征的神经元节律性放电，使它们的信号更突出、传递更高效。此外，
人类注意力还涉及警觉、定向与执行控制等多个网络的协同。斯特鲁普任务是经典例证：
当用蓝色墨水写“红”字时，人会因读字本能自动激活并产生冲突，必须调用前额叶等
区域的执行控制网络抑制本能，才能准确说出墨水颜色。

### 二、Transformer 的注意力：同名，不同“意”

将人类注意力与 Transformer 自注意力对比，两者共享“选择性关注信息”的原则，
但差异显著。

下列比较中，A = 人类注意力，B = Transformer 自注意力。

- **核心约束**
  - A：硬性生物学瓶颈，同时约三至四个物体，工作记忆容量有限。
  - B：算力与架构瓶颈，理论上可处理整个序列，但长序列会出现注意力稀释或崩溃。

- **信息通路**
  - A：前馈与反馈并存，循环、动态、可重写。
  - B：主要是前馈，信息从底层向高层单向流动，缺乏广泛反馈回路。

- **意图来源**
  - A：内生且目标驱动，由目标、期望、当前任务主动引导。
  - B：外部给定，权重由输入数据间的相关性计算得出，没有内在目标。

- **功能侧重**
  - A：警觉、定向、执行控制多网络协同，能抑制干扰、解决冲突。
  - B：更接近定向，根据相关性分配资源，但缺乏执行控制能力。

一个常见误解是：自注意力“每个词都要和前面所有词计算关联度”，所以“每个词和前面
词的关联度都很高”，模型过于发散。事实并非如此。对第 t 个词，模型确实会计算它对
前面每个词的 query-key 相似度分数，但随后会做 softmax 归一化。这组权重总和为
1，是竞争性分配：某个词权重高，别的词必然低。它不是均匀分配，是在做相对选择。
多头注意力进一步让不同头分工，有的关注相邻词，有的关注句法结构，有的关注指代或
全局 token。低层更关注邻近词与表面模式，高层才做长距离语义关联。

长上下文时确实会出现注意力稀释或 lost in the middle，关键信息容易被大量无关
token 平均掉，但这更接近聚焦能力不足，不是“每个关联都高”。至于生成内容发散，
那更多与采样温度、top-p、解码策略有关，不是注意力权重均匀所致。

### 三、FFN 与 MoE：记忆是分布式叠加的，不是按领域切片

Transformer 中约三分之二的参数量在 FFN。FFN 并非错误的设计，反而已被比较清楚地
刻画为一种键值记忆：第一层权重充当模式检测器，对输入中特定的文本模式或语义主题
产生响应；第二层权重给出一个输出词表上的概率分布，即当出现这个模式时，接下来
倾向于输出什么。一个 FFN 层内部同时存在大量这样的记忆槽，最终输出是这些被激活
记忆的组合，再通过残差连接逐层精炼。低层记忆捕捉浅层模式，高层才涉及更语义化的
模式。它存储的是大量碎片化的“模式到输出倾向”映射，不是“这个 FFN 是物理学专家、
那个是文学专家”。

MoE 则把 FFN 拆成多个专家，每个 token 只激活少数专家，以节省每 token 的浮点
运算量并扩大容量。但 MoE 的专家并不是按人类学科划分的子网络。路由器本质上是
一个线性映射，隐状态相似的 token 自然会激活相似的专家；所谓专业化，是模型内部
表征空间几何结构的副产品，不是路由器主动学会了“这是数学，派数学专家”。
实证也支持这一点：不同模型回答同一个问题时激活的专家重叠率，并不比回答完全不同
的问题更高；深层网络中语义无关的输入甚至可能激活几乎相同的专家。
专家边界并不对应人类可解释的领域边界。

MoE 的过拟合风险是真实的，但机制不是“在领域内钻太深”，实为路由固化与重复数据被
记住。系统研究显示，当训练数据被重复使用时，MoE 比同等活跃参数的稠密模型更
早过拟合：MoE 在约四倍重复时开始退化，稠密模型约在八倍；重复到三十二倍左右，
MoE 甚至可能不如稠密模型。机制在于路由在训练早期就趋于稳定，专家专业化程度
与对重复数据的过拟合呈正相关——路由器反复把熟悉的 token 送往几乎相同的专家，
专家逐渐记住这些重复模式，没有学到可迁移的规律。负载均衡损失本身也在专业化与
泛化之间制造张力：它抑制隐状态中的共享方向以维持路由多样性，副作用是可能阻碍
有意义的领域专业化，也可能在数据多样性不足时加剧专业化坍缩。

因此，一个更准确的判断是：需要拆分的是记忆，不是网络。如果痛点是知识容量、
更新与过拟合，拆记忆比拆计算路径更对症。FFN 确实是可拆的记忆载体，但记忆不是
数据库行，是分布式叠加的权重模式。按人类学科硬切 FFN 会遇到叠加干扰、
多义共享与组合泛化被切断的问题。更合理的形态是：共享组合骨干负责语言、指代、
时间、因果、动作图式、社会常识与任务切换接口；领域事实放入条件激活的稀疏
记忆片；路由可监督、可解释；组合层负责跨片约束。业务可以分片，接口与公共
基础设施必须共享。

### 四、任务级正交性与独立分支并行

不同任务在脚本层面确实存在大量不重合。以日常活动为例，用餐涉及地点选择、点单、
进食、结算；工作涉及通勤、打卡、会议、邮件处理。这些动作、目标、环境与时间尺度
差异明显。若模型要同时学习许多此类任务，硬塞在同一组参数中会互相干扰。这正是
模块化、条件计算、任务条件稀疏记忆有价值之处：共享骨干加任务或情景条件记忆片，
按当前上下文激活对应片，减少干扰、扩大容量。

但不重合不等于可以切成孤岛。不同任务共享语言与指代，共享时间与计划推理，共享
常识与资源约束，共享拿、走、看、说、等待等底层动作图式，也共享目标状态管理与
任务切换。自然语言中任务经常嵌套、混合、临时切换。硬按任务切分，会把跨任务的
组合推理切断。所以可拆的是情景脚本与任务状态，不是把所有底层 FFN 切成互不通信
的领域孤岛。可行形态是：共享组合骨干加任务或情景条件记忆片，配以可监督路由与
跨片组合层。

独立叙事分支同理。若两条分支之间没有直接关联，正确做法不是把它们拼进同一个
上下文让注意力去学“它们无关”，作为两个独立序列或批次并行，各自拥有独立的
KV cache、独立的残差流、独立的因果链，共享只读的世界知识，需要比较或合并时再
通过显式跨分支接口同步。Transformer 在批次维度本来就能并行多条序列；自回归只在
每条序列内部串行。真正的分支并行需要块对角或分支感知的注意力掩码、独立 KV
cache 与残差状态、树状或 DAG 位置编码、共享只读记忆，以及需要时才启用的显式
汇合层。并行不消灭串行性：每条分支内部仍然是因果串行的，并行的是分支之间；
分支状态同步、汇合冲突消解、共享知识一致性，都需要额外机制。

### 五、回视、未定稿状态与记忆重建

人类阅读不是逐字扫描。读者会先看标题，凭阅读习惯跳读，注意到某些部分，遇到不懂
再回头。心理学称这一现象为回视，英文为 regression，亦称回扫。回视不只是再看
一眼，是用后面读到的信息回头强化、改写对前面内容的理解。先读第四段再读第二段，
理解不会崩溃，因为阅读本来就是非线性、可回溯、可重编码的。

更关键的是，未注意不等于未加工。前注意加工与无意识语义加工仍在进行，只是未进入
注意焦点和工作记忆。当人想象一张图时，未注意到的部分并非不存在，处于未定稿、
多候选、低分辨率的状态。一旦回视、追问或描述，它才收敛为一个可报告的具体版本。
人与人的差异不只在于记忆里存了什么，更在于注意如何从这种未定稿状态中采样、
定稿、回视和重写。注意不只由记忆与经验决定，也受物理环境、身体状态、当前任务与
自我状态约束。两个人即使记忆库相同，注意采样策略不同，后续轨迹就会分叉。

记忆也不是录像带。提取不是读取，是重建；重建会改写原记忆。当前的判断与决定会
影响人对以往记忆的看法。人类记录的意义不在于完整保存过去，而在于提供复现与再
巩固的接口：不需要复述所有细节，任何一点线索都能激活重建，并继续加深或改写。
回视触发的是重编码与再巩固，不是回视本身具有魔力。思维可以简化为一动态稀疏图：
节点是概念与情景，边权平时未定，注意时显化当前最强的几条边，回视再改写边权。
记忆是不断生长的。

当前自回归模型能回头看，但不能改前面的笔记。生成到第十个词时，注意力可以重新
读取前面一至九个词的 KV，所以后面的词会受前面影响；但前面词的隐藏状态在生成后
基本冻结，KV cache 是只读的。它不能像人一样读到后面、回头把前面那个词的理解再
强化或改写一遍。编码器模型有双向注意力，能反复关联整段文本，但不是自回归生成，
也没有边读边改工作记忆的循环。模型缺的是可重写的工作记忆与主动回视机制，
不是缺看前面的能力。

### 六、上下文管理的结构性缺陷

由此可以看清当前大语言模型的结构性短板：它把所有内容堆叠在同一上下文里。写代码
改三版，三版都留在上下文中，注意力每一步都要在全部 token 上计算权重。模型没有
显式的废弃与提交标记，无法区分哪一版是草稿、哪一版是当前有效版；重要与不重要
信息混在同一条残差流中，长上下文还会稀释关键信息。它更像一堆未提交的草稿，
工作区与全部历史挤在一起，缺乏版本管理。

版本控制系统的本质不是记住所有事，是选择性保留与可回退：工作区只放当前
有效版，使当前推理与编辑保持干净；历史存在版本库，需要时检出、比较、追溯；
显式标记哪些是提交、哪些是废弃、哪些是分支；不需要把每一步都塞进工作记忆，
因为外部系统替人管理历史。当前模型缺的正是这套上下文管理：提交与废弃语义、
可回退的版本层、分支隔离、摘要压缩、按需检索。

### 七、方向：外部化记忆与上下文版本管理

方向不是继续堆上下文，也不是在模型内部另造一套复杂的记忆模块。复杂架构此前已被
反复验证容易失效。更简单可靠的路径，是把 LLM 视为能够读写外部存储的 agent：
围绕一个观点生成一篇文档，存入文件系统；用目录组织，用版本控制管理历史，
用关键词检索定位内容。多个 LLM 可以并行推进，各自总结，直接写入外部存储。
人类没有可随时列出的记忆文件树，LLM 有；人类记忆会掩埋、遗忘、曲解，LLM 可以
读取、比较、检出。文件系统本身可以充当记忆树，版本控制可以充当再巩固机制。

这一方向可以只加少量轻量结构。第一，文件头写标题与标签，解决不可读文件名的
问题。第二，根目录放索引文件，每篇一行摘要，检索前先扫索引。第三，同义词
别名表，缓解关键词检索漏同义词的问题。相关观点可以用关联字段串起来，形成
轻量图，检索时顺藤摸瓜。写入即提交，提交信息用一句话说明本次新增观点；提交日志
就是思维时间线，关键词检索能查某个观点何时出现、如何演化。一篇一个核心观点，
控制长度，短文件加清晰标题与标签，检索精度会更高。

所谓“高浓度知识集合”，可以理解为一个面向 LLM 高效读取的知识单元：把一段经验、
一个观点或一组关联压缩成模型能够直接展开、检索和组合的形式。

这个单元最值得注意的地方在于读取方式的不对称。LLM 读取时接近无损：它直接展开
高维结构、关联与条件，不需要先转译成自然语言，也不经过工作记忆瓶颈。人类读取时
只能有损解压：必须转成文字、图示或讲述，经过注意与理解的窄门，会丢细节、
改结构、掺入自己的解释。因此，这类知识集合不必为了“人能读”而牺牲密度；它可以
主要面向 LLM 设计，人类只在需要审计或修订时进行有损解压。如此，记忆才可检索、
可审计、可更新、可回退，而不是一团不可解释的嵌入；读取它，对 LLM 而言更像加载
一组可直接参与推理的关联，而不是“阅读一篇文章”。

### 八、结论

人类注意力适合承担当前焦点的工作记忆，像一块黑板；长期知识不应全部堆在黑板上，
而应放入可寻址、可版本化、可回视的仓库。当前 Transformer 的问题，不是注意力
算错了，而是把整合与存储合并了：注意力本应做当前上下文的全局黑板，却同时承担了
长期知识的分区仓库；残差流是共享总线，所有信息都往同一条表征里叠加，导致知识
分布式纠缠，难以隔离、更新与回退。

LLM 真正的优势不是记得多，而是记录外部化、检索低成本、分支可并行。将记忆外化为
文件树，将历史交给版本控制，将回视变成读取旧文件，将重写变成修改后再提交；
独立分支放在独立上下文与独立 KV 中并行，只在需要时显式汇合；专有知识拆成带
元数据的稀疏记忆片，共享骨干保留语言、因果、动作图式与组合推理。这比在隐空间里
构建复杂记忆架构简单得多，也可靠得多。人类记忆会掩埋、遗忘、曲解，而 LLM 的
记忆可以列出、读取、比较、检出——这是当前阶段最值得利用的结构性优势。
